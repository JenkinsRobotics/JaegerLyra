// intended framework

Ears. Inference. Control. Voicebox.

Four responsibilities in one audio project. The alpha establishes reconstruction on the output side; the broader audio-to-audio system is planned.

Offline prototype

01 · Audio encoder

The ears preserve acoustic information from an incoming waveform. Today's encoding supports reconstruction, not semantic understanding.

Planned

02 · Perception

Extract meaning, speaker cues, intent and context while retaining acoustic expression.

Manual / captured

03 · Controller

Determine articulation, timing and expression. Independent generation of this plan remains research work.

Reconstruction works

04 · Waveform decoder

The voicebox turns acoustic controls into waveform samples. This is the component demonstrated today.

The intended design has no mandatory transcript bottleneck. Text and musical scores can be optional inputs. JaegerOS integration and a stable production API are planned.

// standalone alpha

Run Lyra in its own environment.

Python 3.11–3.12. The prepared demo bundle is included; no avatar application or external model download is required.

terminal · local reconstruction demo
git clone https://github.com/JenkinsRobotics/JaegerLyra.git
cd JaegerLyra
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jaeger_lyra --port 8794

Then open http://127.0.0.1:8794/. Audio begins only after you press a playback button.
