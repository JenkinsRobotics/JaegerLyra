# Jaeger Lyra 0.1.0-alpha.1

Initial standalone R&D snapshot, November 7, 2026. Further model development is deferred after this handoff.

## Included

- Independent neural reconstruction playback from prepared continuous acoustic controls.
- Eighteen complete words, explicit held-vowel mode and nine phrase comparisons.
- Pitch, volume, resonance, brightness, pace and vibrato controls.
- A standalone `.venv` setup, pinned dependencies, included demo bundle and an isolated-checkout smoke test.
- Explicit Kokoro-source/Lyra-reconstruction labels in the app and public overview.
- Architecture and status documentation for the proposed ears → inference → controller → voicebox path.
- Preserved research, tests, provenance and local reference infrastructure from the avatar prototype.

## Platforms

macOS on Apple Silicon is a primary platform, verified locally on macOS 26.6.2. The maintained alpha branches also run CI on macOS 26 ARM64 and Linux. Intel Mac compatibility is not yet verified.

## Validation

163 core numerical tests, 14 runtime/colour tests, 26 legacy-adapter tests and six browser-audio tests passed locally. All 119 packaged file hashes passed. Nine phrases preserve neutral reconstruction while vibrato produces a nonzero change. An isolated copy containing only shipped source and the bundle successfully reconstructed a word without the avatar folder or external reference models. Separate silent HTTP checks cover complete words, explicit holding and 198 shaped catalogue renders.

These are engineering checks. They do not demonstrate natural unseen speech, general singing, short-reference voice cloning or semantic audio understanding. The current model and source performances remain derived from Kokoro-generated audio.

## Start

See the repository README. This alpha runs from a source checkout with Python 3.11–3.12; it is not a production model-server distribution or a completed JaegerOS module.
